# FrescoSense 3.0

Refrigerador inteligente que detecta la descomposición de los alimentos con sensores de gas, CO₂, temperatura, humedad y peso, dividido en 3 zonas (carnes, pollo y pescado; lácteos; frutas y verduras).

Esta página muestra el panel con **datos simulados**, las secciones Cámaras y Software, y un botón con código QR para abrirla en el celular.
